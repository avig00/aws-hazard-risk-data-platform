# Assets

This folder is the canonical location for README media assets.

Recommended filenames:

- `risk-explorer-screenshot.png`
- `risk-explorer-demo.gif`

Recommended README embed usage:

- `![Risk Explorer screenshot](docs/assets/risk-explorer-screenshot.png)`
- `![Risk Explorer demo](docs/assets/risk-explorer-demo.gif)`

Keep assets lightweight so GitHub renders them quickly.
